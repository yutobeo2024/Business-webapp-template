# Spec nghiệp vụ

Mỗi quy trình một file `NNN-ten-quy-trinh.md`, tạo bằng `/business-flow`. Chỉ code khi spec ở trạng thái "Đã duyệt".
Nghiệp vụ thay đổi sau khi duyệt: sửa spec trước, code sau. Mỗi BR-xx phải có test dẫn đúng mã đó.

<!-- sample:begin -->

`001-phieu-de-nghi-mua-hang.md` là spec MẪU, khớp với module mẫu phiếu đề nghị. Trước module thật đầu tiên, gỡ cả
spec lẫn module bằng `pnpm sample:remove`.

000 (quản trị), 002 (tệp và xuất file), 003 (thông báo, nhập Excel) là spec của LÕI: giữ, sửa khi đổi hành vi lõi.
